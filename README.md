# RhythmGraph

**RhythmGraph** is a Spotify-inspired web app built with [Plotly Dash](https://dash.plotly.com/) that transforms your Spotify listening data into beautiful, interactive dashboards.  
It helps you visualize your top tracks, genres, and artists — just by uploading your exported Spotify history files.

---

## Features

- **Upload Spotify data (JSON)** — Directly upload your exported Spotify listening history.  
- **Automatic parsing & redirect** — After uploading, the app automatically processes your data and navigates to the dashboard.  
- **Multi-page dashboard** — Explore multiple views like:
  - Overview  
  - Top Tracks  
  - Top Artists  
  - Genres  
  - Track Features  
  - Listening Journey
- **Spotify-like design** — Dark interface, green accents, and fluid layout.  
- **Smooth fade-in transitions** between pages — clean, fast, and modern.  
- **Modular file structure** — every page and utility is neatly separated for scalability.
